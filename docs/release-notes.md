# 密码工坊 1.1.0

- 支持随机密码、英文单词与汉语词汇/成语拼音易记密码、数字 PIN。
- 提供词库及分隔符单选、长度与字符组合设置、隐藏、更换和复制。
- 使用 shadcn/ui、Lucide、社区配色及减少动效偏好；操作反馈使用顶部 Toast，适配顶部安全区域。
- 词库与生成逻辑随应用打包，运行时使用 Web Crypto，不上传或保存密码历史。
- 页面提供开源地址、完整源码提交及指纹。Release 包含上传包、文件摘要和构建信息，支持本地复现与实际包比对。

上传 Linux DO 的文件为 `app.zip`；其他附件用于核验。GitHub Release 不代表社区应用已完成上线或审核。
